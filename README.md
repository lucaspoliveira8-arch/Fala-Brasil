# FalaBrasil

Website educacional para ensinar português brasileiro para pessoas ao redor do mundo.

## Recursos incluídos

- Seleção de língua materna para facilitar o aprendizado.
- Tema com cores da bandeira do Brasil + modo escuro.
- Seções de gírias por região: São Paulo, Rio de Janeiro, Goiás, Nordeste e Sul.
- Verbos e conjugações organizados por nível: iniciante, intermediário e avançado.
- Trilhas de conversação para viagem ao Brasil (básico ao avançado).
- Simulador de treino com AI para praticar cenários reais.
- Laboratório de pronúncia focado em sons importantes.
- Mapa de fluência com agente que identifica pontos fracos e recomenda exercícios.

## Executar localmente

```bash
python3 -m http.server 8000
```

Depois abra `http://localhost:8000`.
